# Getting Started

Welcome to Doc Patrol! This guide will help you get started with our documentation scanning tool.

## Installation

To install Doc Patrol, run:

```bash
npm install -g doc-patrol
```

For more details, visit our [SDK documentation](https://docs.docpatrol.example.com/sdk/v2).

## Quick Start

Create a configuration file:

```yaml
api_key: YOUR_API_KEY
scan_interval: daily
```

Then run:

```bash
doc-patrol scan https://your-docs.com
```

## Authentication

Use the [authentication guide](https://docs.docpatrol.example.com/auth) to set up your API keys.
